# Decisions

Every non-obvious choice in this repo is written down here once, with its
reasoning, so the why survives and nobody relitigates a settled question by
guessing.

- Each record is numbered, dated, and append-only.
- A record is Accepted until a later one Supersedes it. History is added to,
  never edited.
- If you are about to do something a record forbids, either follow it or write
  the record that overturns it.
- Copy `TEMPLATE.md` to start one. Number it next in sequence. The filename is
  the number and the title in kebab-case: `0001-one-list-is-real.md`.
